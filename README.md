# CS2 Flip Mode Registry Setup

1. Run `DefaultRegKeys.reg` first to get rid of any old fso tweaks.
2. For **Independent Flip** in fullscreen, run `FSO.reg`.
3. For **Legacy Flip** in fullscreen, run `DFSO.reg`.
4. Fully restart CS2 after applying any registry file.

Always test both modes on your own system, as results can vary by PC.
